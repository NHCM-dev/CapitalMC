# CapitalMC 0.2.0-SNAPSHOT

Changes since [`9a56ac3`](https://github.com/NHCM-dev/CapitalMC/commit/9a56ac374e10275921f3e67f92f232648fcfd5cb).

## English

- Bundle AdvMatch 1.2.0 and add a dedicated exchange-settings GUI for trading rules, contract price protection and its percentage, reference prices, schedules, exchange halt/resume and checkpoints. Changes use existing administration permissions, confirmations and audit records.
- Show the account's available quote balance before entering an order price. Improve quantity estimates and percentage selection using available market data, with submission still validated by the exchange.
- Reorganize deposit/withdrawal and transfer flows with asset search, account navigation and owned-asset selection. Clear selected assets when leaving these pages, preserve selection during private prompts, and show available amounts in quantity prompts.
- Add confirmed deposits of empty chests and shulker boxes for container credits. Credits support existing container withdrawals and cannot be redeemed directly into containers.
- Register `mc_exp` / `Exp` automatically with unit 1 and support experience-point deposits. Treat Exp as a special asset: block item binding, issuance, burning, administrator balance adjustments and pegged exchange; retain trading and transfers. No experience withdrawal is provided.
- Display ledger circulation, total balances and cumulative net credits for all registered assets. These figures describe exchange balances and exclude items or experience outside the exchange.
- Restart full-list reads on cursor expiry with a bounded retry budget, discarding partial rows from the expired revision. Other failures remain visible.
- Improve login/account layout, gray-glass separators, button placement, audit navigation and bilingual tooltips. Add the About page, `/trade about` and `/trade about gui`.
- Guard missing Windows process information during system-report collection to prevent the OSHI null-process warnings.
- Update bilingual guides and command reference, and add the repository's GPL-3.0 license file.

### Installation and recovery

Requires Minecraft 26.3, Fabric Loader 0.19.5+, Fabric API and Java 25. SGui and the Windows amd64 AdvMatch SDK are bundled in `CapitalMC-0.2.0-SNAPSHOT.jar`.

Back up the Minecraft world, AdvMatch persistence directory, `users.json`, and both `services.json` and `services.json.wal`. Minecraft saves and the exchange WAL are separate durability boundaries; custody operations with unknown outcomes remain quarantined for recovery. Exp is the automatically registered built-in asset; configure other assets and markets as needed.

## 简体中文

- 内置 AdvMatch 1.2.0，新增独立交易所设置页面，可管理交易规则、合约价格保护及比例、参考价格、合约时间安排、全所暂停/恢复和检查点；沿用管理员权限、确认和审计流程。
- 未填写价格时也展示账户可用 quote 余额，利用行情改进数量估算和百分比选择；提交订单仍以交易所校验为准。
- 重整充值/提款与划转流程，支持资产搜索、账户导航和已有资产选择；离开页面清空选择，私有输入期间保留上下文，数量提示显示可操作余额。
- 支持确认充值空箱子和空潜影盒以获得容器额度；额度用于已有容器提款流程，不能直接兑换出容器。
- 自动注册单位为 1 的特殊资产 `mc_exp` / `Exp`，支持充值经验点数。禁止绑定物品、发行、销毁、管理员增减余额和锚定兑换，保留交易和划转；不支持提取经验。
- 所有注册资产支持展示交易所账本流通量、余额总量和累计净入账，不统计交易所外的物品和经验。
- 全量分页查询遇到游标过期时有限重读，并丢弃旧版本的部分结果；其他错误继续正常报告。
- 优化登录与账户布局、灰色分隔玻璃、按钮位置、审计返回和中英文提示；新增关于页面及 `/trade about`、`/trade about gui`。
- 修复 Windows 系统报告收集遇到空进程对象时的 OSHI 警告，完善中英文文档，并加入 GPL-3.0 许可证文件。

运行环境：Minecraft 26.3、Fabric Loader 0.19.5+、Fabric API、Java 25。产物 `CapitalMC-0.2.0-SNAPSHOT.jar` 内置 SGui 与 Windows amd64 AdvMatch SDK。

升级前备份世界、AdvMatch 持久化目录、`users.json` 及配套的 `services.json` / `services.json.wal`。世界保存与交易所 WAL 为独立持久化边界，结果未知的托管操作仍隔离等待恢复。Exp 会自动注册，其他资产和交易对需自行配置。
