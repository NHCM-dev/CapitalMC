## 玩家操作

| 命令 | 用途 |
| --- | --- |
| `/trade gui` | 打开交易所 |
| `/trade`| 账户、余额、存取款和交易命令 |
| `/cmcadmin gui` | 打开管理页，需要 owner 权限 |
| `/testgui <page>` | 开发时预览页面 |

未登录时，首页只显示登录 / 注册入口。登录后开放交易页面，退出登录会清除受限页面的返回记录。

聊天问答仅自己可见，按提示示例回答，输入 `cancel` 返回。大部分问题限时 30 秒。密码不会回显。

**交易：**选择交易对及方向。合约提供开多、开空、平多、平空。点击盘口档位设置限价；市价单使用保护边界，需要有效对手盘。25% / 50% / 100% 按钮结合资金、手续费、流动性和规则估算数量，最终由交易所校验。

**盘口：**左键红石比较器打开完整订单簿，右键调整深度与显示配置。白色玻璃板表示空档，附魔选项表示当前选择。

**充值：**进入丢物选择后，用 Q 选择一个、Ctrl+Q 选择整组，可选择多个背包槽。容器充值时右键符合条件的箱子或潜影盒。输入 `done` 汇总，核对后输入 `yes`。选择时不移走物品，确认前整批重新校验。

**划转与兑换：**在划转页选择资产及账户方向。锚定兑换会在确认前显示支付与到账资产。实物资产可提款为物品，电子资产保留在账本中。

## 管理员配置

新实例默认没有资产和交易对，由管理员通过 GUI 或命令配置。

1. 用手持物品注册实物资产，或创建电子资产。
2. 配置显示单位、最小充值及提款数量；物品匹配包含组件和耐久。
3. 创建交易对，配置价格步长、数量步长、最小订单及合约规格。
4. 补充锚定兑换储备，并为合约配置参考价格。

配置采用逐项聊天问答与最终预览。存取款及兑换在单位允许时支持精确小数输入。

价格步长只要求价格对齐，不要求下一笔上涨。合约保护带支持至少上下各一档价格的范围，由交易规则控制。缺少有效指数来源时，标记价可能保持初始值，应配置同资产现货市场或外部来源。订单提交成功不代表已经成交。

## 持久化与备份

账户和应用元数据使用二进制快照与 WAL；金融账本由 AdvMatch 管理。存储位置和恢复方法见[持久化文档](persistence.zh-CN.md)。Minecraft 世界存档与交易所日志分别落盘。

停服后进行配套备份。保留托管和恢复证据，不重复执行结果不确定的充值、提款或交付。SDK 与原生库须配套使用。

## 仓位保护

点击仓位进入详情页。市价全平只需确认；市价部分平仓填写数量；限价平仓填写价格。追加 / 减少保证金仅限逐仓。止盈止损支持成交价、标记价、指数价触发、市价 / 限价执行与 OCO 关联。触发后检查委托状态，是否成交取决于资金与盘口。

## 交易设置

从管理页打开“交易所设置”，或使用 `/cmcadmin market settings <symbol>`。选择交易对后可配置步长、最小下单、手续费、敞口限额、自成交保护、合约成交价格保护、参考价格及资金费周期。每项显示单位与影响；修改需填写审计原因并确认，重启后保留。全所暂停、恢复和检查点位于独立标签页。

价格保护输入小于 100 的百分比；0 关闭成交保护。再次开启默认使用 10%，也可直接输入其他幅度。市价单及止盈止损单的独立保护价、资金检查和有界强平价格仍有效。最小一档选项仅扩展非零保护范围。

充值页面支持消耗主手中的空箱子或空潜影盒来增加容器额度；额度仅用于容器提款，不能兑换回容器。经验充值按经验点数扣除，每点记为现货账户中的 1 Exp（资产名 `mc_exp`，单位 1）；启动时自动注册，不能提款为经验或物品。

这些充值共用存款托管记录：先保存托管意图，重新校验并扣除物品/经验，再保存 Minecraft 数据，最后入账或增加额度。Minecraft 存档和交易所账本是独立存储；未完成记录在重启后隔离核查，不自动重试。

Exp 为特殊资产：只能由经验充值增加供应，不支持物品绑定、发行、销毁、管理员余额增减或锚定兑换，单位固定为 1。仍可参与交易和账户划转。所有资产详情显示累计净入账、账本总量和流通量；流通量排除发行账户持有量，统计不包括尚未充值的游戏物品或经验。

## 交易记录与交割日期

订单、持仓、止盈止损和成交记录按交易类型统一查询所有交易对。记录显示 UTC 创建、更新时间，订单还显示首次/最后成交及完成时间。最新记录排在左上方。切换记录分类后，返回仍回到进入列表时的交易页或账户页；重新进入列表从最新一页开始。

已平仓记录显示已实现盈亏、资金费和已付手续费。未成交就撤单产生的空仓位不计入历史仓位。全平后引擎会清空当前数量、均价，历史页面不会将这些当前值当成历史成交数据。平仓订单保留在历史订单中。

交割合约可通过 **合约信息 → 交割日期** 或 **交易所设置 → 时间计划** 设置实际交割日期。管理员可输入 `2027-01-31`、`2027-01-31 12:00:00`（UTC）、带时区的 ISO 时间或 Unix 毫秒；日期必须在未来。合约信息显示已配置的交割日期与合约状态。
